# Third-party OKF sample bundles (vendored for interoperability testing)

These files are **unmodified** OKF concept documents copied from Google Cloud's
reference repository, vendored here so the VKF test suite can prove — offline and
in CI — that real, published OKF bundles validate as VKF at Profile 0 (the
"strict superset of OKF" guarantee).
